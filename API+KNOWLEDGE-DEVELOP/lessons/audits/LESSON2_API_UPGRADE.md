# שיעור 2 — קורא-המודל (L2) ושדרוג ה-API

*29/07/2026 · Opus 4.8 · מודל: `שיעור 2.dwg` (857 ישויות)*

## 1. מה נבנה — קורא-מודל סמנטי (L2)
עד היום הסוכן **יצר** אלמנטים אך לא ידע **לקרוא** מודל קיים ברמה סמנטית (רק מלאי "מזהה+סוג+שכבה"). נבנה `EBAgentApi9.dll` / `EB_RUN9` עם op חדש **`dumpmodel`**:

| אובייקט | מה נקרא | ה-API שבו |
|---|---|---|
| `Ks_Shape` ✅ | פרופיל, **קטלוג**, נק' התחלה/סוף מדויקות, אורך, חומר, שם | `CrossSectionName`, `CrossSectionCatalog`, `GetMidLine(a,b)`, `Length` |
| `Ks_Plate` ⚠️ | טרם — `NullReferenceException` | הקאסט `GetObject(id) as PsPlate` לא מספיק |
| `Ks_Bolt` ⚠️ | טרם — כנ"ל | כנ"ל |

**תוצאה בפועל: 175 פרופילים נקראו במלואם.** דוגמה אמיתית מהמודל שלך:
`RHS200X100X4 | BRITAIN.BS_CELSIUS_RHS | (454.8, 3312.9, 4106.5) → (454.8, 3312.9, 7106.5) | 3000 מ"מ`

**מלאי המודל שזוהה:** RHS150X100X4 ×29 · EA60X60X6 ×27 · BSC21.3X2.5 ×27 · 50X3.0SHS ×19 · 40X2.5SHS ×19 · 26,9X2,6 ×15 · 300X12 ×10 · U140 ×9 · BG60X6 ×7 · ועוד — מ-9 קטלוגים (אוסטרליה, בריטניה, שוודיה, DIN, צרפת, סין).

## 2. ⚠️ אזהרה קריטית שנרשמה (טעות שעשיתי ותוקנה)
ניסיתי לפתור את קריאת הפלטות/ברגים באמצעות **מעבר רפלקטיבי** (`PropertyInfo.GetValue`) על אובייקטי ProSteel → **AutoCAD קרס** ("AutoCAD Error Aborting").
**כלל חדש ומחייב: אין להריץ רפלקציה עיוורת על אובייקטי `Ks_*`.** יש להשתמש רק בגישה מוטיפסת עם try/catch פרטני. הפלאגין הבטוח = **v9**. (v10 קיים בקוד אך אינו לשימוש.)
**נוהל התאוששות שאומת:** סגירת AutoCAD → שיגור מחדש עם פרופיל ProStructures (`/p ...ProStructures_SS6...arg /t Ps191_Metric /ld ProStructuresLoader.arx` + נתיב ה-DWG) → NETLOAD v9 → ping. עובד תוך ~40 שנ'.

## 3. שדרוגי API שנעשו — ישירות מהלמידה
1. **`beam(..., catalog=...)`** — חדש. כשהקטלוג ידוע (מקריאת מודל) הפלאגין **מדלג על כל הניחושים** (עד כה ניסה 7 קטלוגים × 3 וריאציות שם). זה מקור מרכזי למהירות בשכפול.
2. **`dumpmodel()`** ב-`eb_api` — מחזיר רשימת אלמנטים מפורשלת (dicts), בסיס לכל יכולת "שחזר/העתק/נתח מודל".
3. **`fire(cmd)`** — הרצת פקודת ProSteel גולמית שאין לה עדיין API.
4. **NLU: "בדוק התנגשויות"** → מריץ `PS_COLLISION`. (בשיעור 1 הרצת אותה ידנית.)
5. **NLU: "עצור" / "המשך"** → שליטה חיה בריצות ארוכות.
6. **`live_rebuild.py`** — מנוע שכפול-לייב: קורא מודל → מתכנן → בונה אלמנט-אחר-אלמנט בקצב צפייה → מדווח לקונסולה → מקשיב לפקודות שלך → מייצר דוח השוואה. **כל תיקון שאתה כותב בזמן ריצה נשמר ל-`LEARNED_PATTERNS.md`.**

## 4. מאקרואים מתוכננים — ממתינים לאישורך (לא נבנו)
מהניתוח של שיעור 1: הכלים שבהם **ביטלת 100% מהפעמים** הם דיאלוגים פרמטריים. התכנון:

**א. `endplate` — פלטת קצה עם ברגים**
`"שים פלטת קצה 200×150×15 עם 4 ברגים M20 בקצה הקורה"`
מימוש: זהה את קצה הקורה (מ-`dumpmodel`) → צור `plate` בנורמל של ציר הקורה → `boltfield` 2×2 במרווח מחושב → קבץ. מחליף את `PS_ENDPLATE_NORM`.

**ב. `groundplate` — פלטת יסוד**
`"פלטת יסוד 300×300×20 מתחת לעמוד"`
מימוש: קח את נקודת הבסיס של העמוד → `plate` אופקי במרכזה → 4 ברגי עיגון. מחליף את `PS_GROUNDPL`.

**ג. `serial_copy` — שכפול סדרתי**
`"העתק את החיבור לכל 6 העמודים במרווח 1.5 מ'"` — מחליף 24 הפעלות `PS_COPY` ידניות.

## 5. הצעד הבא
1. **פתרון קריאת פלטות/ברגים** — שני מסלולים לבדיקה: (א) `PsSelection.SelectAllObjects(true)` כמסלול נייטיבי; (ב) זיהוי חיבורים לפי פרופילים נפגשים ושחזור דרך `conn_bolted` במקום קריאה פרטנית.
2. **אישור המאקרואים** (א/ב/ג) ובנייתם.
3. **מבחן השוואה מלא** — אותו מקטע ידנית מול הקונסולה, עם סטופר.
