## הכלל שמגן על העבודה של אמיר

> **בזמן שאמיר ממדל — הסוכן לא נוגע ב-AutoCAD.**

שליחת פקודה ל-AutoCAD תפוס מפריעה לסשן שלו (וגם נחסמת). לכן:
- **הפלאגין מקליט מבפנים** — כותב `jsonl` ישירות מתוך התהליך, בלי שאף אחד יבקש ממנו כלום.
- **`watch` קורא רק את קובץ הלוג מהדיסק** — אפס מגע ב-AutoCAD.
- נוגעים ב-AutoCAD **בשתי נקודות בלבד:** בהתחלה (snapshot + הפעלת ההקלטה) ובעצירה (כיבוי ההקלטה + snapshot).

## מה מוקלט (השיפור מול שיעור 1)

בשיעור 1 ההקלטה תפסה **פקודות בלבד** — ידעתי ש"אמיר הריץ PS_ENDPLATE_NORM" אבל לא **מה יצא מזה**. זה תוקן ב-v21:

| שכבה | מה נתפס |
|---|---|
| **שיטה** | כל פקודה · ביטולים ו-UNDO · סדר העבודה · זמנים |
| **תוצר** (חדש) | לכל אובייקט שנוצר, אחרי שהפקודה מסתיימת: **פרופיל + קטלוג + אורך + נקודות קצה** · או **מידות פלטה + מספר קודקודי קונטור** · **חורים שנקדחו** · **המחבר** (סוג, מספר פלטות, מספר ברגים) |
| **דלתא** | snapshot מלא לפני ואחרי: פרופילים · פלטות · ברגים · **חורים** · **מחברים** |

הקריאה נעשית ב-`cmd_end` ולא ב-`ObjectAppended`, כי בזמן שהאובייקט נוסף הוא עוד לא קריא. פקודה שבוטלה — מה שנוצר בה נזרק מהרשימה.

## הפקודות (בצ'אט)

```
python lesson.py wait                    # מחכה שאמיר יפתח את התוכנה
python lesson.py start <מספר> "<תוכן>"   # פותח שיעור: snapshot + הקלטה ON
python lesson.py watch [שניות]           # צפייה חיה — קריאת לוג בלבד
python lesson.py stop                    # הקלטה OFF + snapshot סוגר
python lesson.py analyze                 # הדוח
```

התוצרים נשמרים ב-`projects/שיעור-<n>/`: ההקלטה ב-`learning/`, ה-snapshots והדוח ב-`files/`.

## מה הדוח מפיק
1. **מה השתנה במודל** — דלתא מדודה בפרופילים/פלטות/ברגים/חורים/מחברים.
2. **איך אמיר עבד** — הפקודות שהשתמש בהן, שיעור הביטולים, סדר הפעולות.
3. **מה הוא בנה** — פר-פקודה, עם הפרמטרים האמיתיים: איזה מחבר, אילו מידות, כמה חורים ובאיזה קוטר.

## כללי הזהב שנשארים בתוקף
- **אין דיווח בלי קריאה-חוזרת.** אימות = הנתון מהמודל, לא צילום ולא הד-קלט.
- **היחידה היא המחבר, לא האובייקט** (`steel/08-CONNECTIONS-AS-OBJECTS.md`).
- בדיקות-עשן ב-X≥40000 ומחיקה מיידית · גיבוי PRISTINE לפני בנייה.
- **כל פרויקט לגופו** — מכלילים שיטה, לא מספרים.
