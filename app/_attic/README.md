# `_attic` — סקריפטים חד-פעמיים משיעורים שהסתיימו

**זו לא זבלה. זו היסטוריה.**

כל קובץ כאן נכתב למשימה אחת, רץ, ועשה את שלו. הם נשמרים כי הם **הרשומה של איך נבנה מודל
מסוים** — לא כי מתכננים להריץ אותם שוב.
