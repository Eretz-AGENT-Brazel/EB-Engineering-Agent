## סדר הפעולות

1. טען את הסקיל `prosteel-modeling`, וקרא `api+knowledge-develop/knowledge/learning/RESUME-HERE.md`.
2. `python "api+knowledge-develop/app/night.py" next`
   - `NONE` ⇒ צא בלי לעשות כלום.
   - `BUSY <path> age=<N>min` ⇒ **אם `age` < 60: צא מיד ובשקט.** אם ≥ 60: סמן `partial`
     ("run interrupted") וקח את הבא.
   - ⭐ מודל שמסומן `partial` הוא **המשך עבודה**: קרא את ה-README שלו, ראה מה נבנה, והמשך מהנקודה
     ההיא במקום להתחיל מאפס.
3. סמן `working`, ואז **מסלול 2** (`api+knowledge-develop/README.md` § מסלול 2):
   - העתק את המקור ל-`projects/<slug>/` (`night.py slug <dwg>`) + עותק `<שם> - REBUILD.dwg`.
   - `eb_api.bootstrap(dwg=<המקור>)` אם AutoCAD לא רץ · `worksession.assign([מקור, rebuild])` ·
     `eb_api.open_model(<rebuild>)` · **`eb_api.build_target(<rebuild>)`**.
   - ⚠️ אשר מיקום עם אופ **מגודר** (`run('list')`) ואז `whoami` — `whoami` לבדו אינו מפעיל מסמך.
   - **קרא את המקור פעם אחת, במלואו, לקובץ JSON** (dumpfull2 + dumpmodel + dumpholes + mods +
     חיתוכי מישור דרך COM `Ks_ComCutPlane.GetNormal()`), ורק אז בנה.
     ⛔ אסור לקרוא מהמקור באמצע בנייה — קריאה עם `dwg=` מחליפה את המסמך הפעיל.
   - בנה: פרופילים → לוחות → חיתוכים → חורים → ברגים.
     ⭐ חורים: לסווג לפי **עומק** מהמקור (עומק = עובי אגף ⇒ `flange=1`; עובי ווב ⇒ בלי `flange`).
     ⭐ ברגים: רק אחרי שהחורים מדויקים — `boltparts` על החיבור. ביד רק כשאין שותף פלדה (עיגון לבטון).
4. ⭐⭐ **שמור מפעם לפעם — הוראת אמיר.** מודלים 5 ו-6 גדולים (785 ו-1,410 חלקים) ולא ייסגרו
   בריצה אחת. עבוד ב**מקטעים מוצהרים** (למשל: כל הפרופילים · כל הלוחות · חיתוכים · חורים ·
   ברגים), ובסוף **כל מקטע**: `run('save')` + `night.py set <dwg> partial <המספרים עד כה>` +
   שומר → קומיט → **פוש**. כך קריסה עולה מקטע אחד, ואמיר רואה התקדמות בגיטהאב במהלך הלילה.
5. **שערי קבלה — כל אחד מורץ גם על המקור, לכיול:** ספירה פר-מחלקה · **מוטת bbox פר-חלק** ·
   חורים (מיקום/עומק/קוטר) · `vfy_fit` · `collision minvol=100`.
   ⚠️ **מודל 5 בלבד: התנגשויות אינן שער.** אמיר הצהיר שיש שם התנגשויות — מודדים, רושמים את
   המספר ב-README, וממשיכים. **בשאר המודלים התנגשות שאינה תואמת את המקור היא כן פגם.**
6. **את המקור לעולם לא שומרים** — בדוק `getsize`/`getmtime` שלו בתחילת הריצה ובסופה והוכח שהם
   זהים, ורשום את זה ב-README. סגור את המסמכים שאתה פתחת.
7. ⭐⭐ **הטמעה בסקיל — הוראת אמיר, בכל ריצה ולא רק בסוף הלילה.** כל לקח שמשנה התנהגות נכנס
   ל-`~/.claude/skills/prosteel-modeling/SKILL.md` או ל-`references/`, ואז `python
   agent-brain/sync.py`. אין לקח חדש? כתוב זאת במפורש ב-README. ⛔ **כותבים סקיל אטומית:**
   לקובץ `.new` ואז `os.replace` — כתיבה שנכשלת אחרי `open(...,'w')` מרוקנת את הסקיל (קרה
   ב-18/08; הגיבוי ב-`agent-brain/skill-prosteel-modeling/` הוא מה שהציל).
8. עדכן `README.md` בתיקיית הפרויקט (מלאי + טבלת שערים במספרים + מה שלא הושלם), שורה ב-
   `PROGRESS.md` **חלק ה**, ו-`night.py set <dwg> done|partial <הערה עם המספרים>`.
9. `python "api+knowledge-develop/qc/consistency.py"` חייב CLEAN → קומיט → **פוש**.
