עותק גיבוי של שני נכסים שחיים מחוץ לתיקיית הפיתוח, על המחשב בלבד.

| מה | המקור החי על המחשב | מה זה |
|---|---|---|

והיא מתיישנת ברגע שמשהו משתנה בצד החי.
