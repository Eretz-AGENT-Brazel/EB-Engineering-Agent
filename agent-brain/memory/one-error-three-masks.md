⚡ **טעות אחת מייצרת כמה תסמינים שנראים כמו מגבלות API נפרדות.** ‏18/08/2026, מודל 2: ארבעה
פרופילים נבנו עם החתך מסובב 90°, וזה נראה כשלוש בעיות שונות — *"`drill at=` לא ממקם חור"* ·
*"פלטה שטוחה `DIN_FLACH` מסרבת לקדיחה"* · *"`boltparts` מסרב בכל החיבורים"*. אחרי בניית ארבעת
החלקים מחדש **שלושתם נעלמו יחד**.

**Why:** ‏`rot` שמודפס ב-`dumpfull2` עושה round-trip ל-90 ול-‎−90 **אבל לא ל-0** — החלקים
חזרו עם ‎h ו-b מוחלפים. הסימפטומים מרוחקים מהסיבה, ולכן כל אחד נראה כמו ממצא עצמאי.

**How to apply:**
- ⭐ **להשוות מוטת bbox (span) של כל פרופיל מול המקור לפני שבונים עליו** — לא להעתיק זווית מדאמפ.
- **שני "ממצאים" באותו סשן שנוגעים באותם חלקים = לחשוד בסיבה אחת משותפת**, לא לרשום שני מבואות סתומים.
- מבוי סתום נרשם רק אחרי שהחלק עצמו אומת מול המקור.
- ‏`flange=1` מנחית חור על האגף המכוון · `flange=0` על הנגדי (‎`h−tf` משם) · מעבר בווב בלי `flange`.
