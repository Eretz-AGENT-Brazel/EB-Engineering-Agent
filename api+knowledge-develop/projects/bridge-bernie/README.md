### 🔩 הברגים: הכשל שהיה מדידה, לא מגבלה

הריצה הראשונה סירבה ל-**2,213 ברגים**, כולם באותה הודעה (`create failed (style '8.8S')`)
וכולם M12. הסגנון לא היה הבעיה: **הציר בדאמפ הוא אורך הבורג, ו-`CreateSingleBolt` קורא
‏`p1→p2` כ-grip.** ‏M12×50 עם grip של 50 דורש בורג 50+1.6·12 — אין שורה כזאת, וזה נכשל בשקט.
ה-grip האמיתי הוא **`KlemmLen` = 24.0**, והוא **לא נמצא באף מסנן תכונות שהקורא שלנו השתמש בו.**
⭐ **ואיפה ה-grip יושב נמדד ולא נוחש:** שלושת העיגונים יוצרים בורג, ולכן ההכרעה גיאומטרית —
‏**מ-`p1`** נתן `org` **זהה בדיוק** למקור; ממורכז החטיא ב-13 מ"מ, מ-`p2` ב-26 מ"מ.
⇒ כל 5,680 הברגים נבנו מחדש עם ה-grip הנמדד.
