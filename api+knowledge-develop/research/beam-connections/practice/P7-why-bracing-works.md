# חלק א' — מסגרת מלבנית אחת עם אלכסון

## א.1 המסגרת הלא-מיוצבת אינה "חלשה". היא **מנגנון**

זו ההבחנה שכל השאר תלוי בה. מסגרת מלבנית עם **ארבעה צמתים מפורקים** (pinned) — שני עמודים,
קורה, ובסיס מפורק — היא **מנגנון בעל דרגת חופש אחת**. היא לא "נכפפת הרבה": היא **מתקפלת
לתקבולית (parallelogram) בכוח אופקי כלשהו, גם 0.001 kN**, בלי שאף מוט יתארך, ואף בלי כפיפה.

```
   H →                        H →                       H →
 ┌───────────┐             ╱───────────╱             ┌───────────┐
 │           │             ╱           ╱             │        ╱  │
 │           │     ⇒       ╱           ╱   δ → ∞     │     ╱     │   δ = H/K
 │           │             ╱           ╱             │  ╱        │   סופי!
 ○───────────○           ○───────────○               ○───────────○
 4 צמתים מפורקים        התקבולית מתקפלת            שילוש: כל שינוי צורה
 mechanism · 1 DOF      אין עיבור באף מוט          מחייב שינוי אורך האלכסון
 K = 0                  ⇒ אין כוח מתנגד            ⇒ הצורה נעולה גיאומטרית
```

| טענה | נכון/לא |
|---|---|
| "נגדיל את העמודים / את הקורה" | ❌ **לא עוזר בכלל.** קשיחות המנגנון היא **אפס**, וכל מספר כפול אפס הוא אפס |
| "נעבור מ-S235 ל-S355" | ❌ חוזק החומר אינו נכנס למשוואה של מנגנון |
| "זה עומד — ראיתי" | ⚠️ אז **הצמתים אינם באמת מפורקים** (ריתוך / פלטת קצה עם ריפים), או שיש **חיפוי/דיאפרגמה** שמייצבת בפועל, או שהוא מיוצב במקום אחר |

⇒ ‏**"לחזק" היא המילה הלא נכונה. אלכסון לא מחזק את המסגרת — הוא הופך אותה לקונסטרוקציה.**

## א.2 שתי הדרכים היחידות לתקן מנגנון

## א.3 ⭐ טיעון הקשיחות, במספרים — למה צירי מנצח כפיפה

**המסגרת שנבחנת:** ‏B = 6000 · h = 4000 · ‏S355 · ‏E = 210,000 MPa.
```
tan θ = 4000/6000 = 0.6667  ⇒  θ = 33.69°       L_d = √(6000²+4000²) = 7211 מ"מ
cos θ = 6000/7211 = 0.8321   sin θ = 0.5547     cos²θ = 0.6924
```

| # | המערכת | הנוסחה | החישוב | **K אופקי** |
|---|---|---|---|---|
| **1** | אלכסון בודד `SHS100×100×5`<br>‏A = 1870 מ"מ² | ‏E·A·cos²θ / L_d | ‏210000·1870·0.6924 / 7211 | **‏37.7 kN/mm** |
| **1b** | אלכסון בודד זוויתן `L90×90×9`<br>‏A = 1550 מ"מ² | אותה נוסחה | ‏210000·1550·0.6924 / 7211 | **‏31.3 kN/mm** |
| **1c** | צלב מוטות `M24` (‏A_s = 353)<br>*רק המתוח פעיל* | אותה נוסחה | ‏210000·353·0.6924 / 7211 | **‏7.1 kN/mm** |
| **2** | ‏2 × `HE200B` **בכפיפה**, בסיס **מוגן** + קורה קשיחה<br>‏I = 5696 סמ⁴ | ‏2 × 12EI/h³ | ‏2 × 12·210000·5.696e7 / 4000³ | **‏4.49 kN/mm** |
| **2b** | אותם עמודים, **בסיס מפורק** | ‏2 × 3EI/h³ | רביע מ-2 | **‏1.12 kN/mm** |

### ולק"ג פלדה — כאן ההפרש נהיה בוטה [חישוב]

```
אלכסון:     7.211 מ' × 14.8 ק"ג/מ'  =  106.7 ק"ג   ⇒  37.7 / 106.7  = 0.353 kN/mm לק"ג
2 עמודים:   2 × 4 מ' × 61.3 ק"ג/מ'  =  490.4 ק"ג   ⇒   4.49 / 490.4 = 0.0092 kN/mm לק"ג
                                                            יחס  =  × 38.6
```
**‏(א) לאלכסון, הקשיחות-לק"ג אינה תלויה כלל בחתך שבחרת:**
```
K/m = (E·A·cos²θ/L)/(ρ·A·L) = E·cos²θ/(ρ·L²)   ← ה-A מצטמצם!
    = 210000 · 0.6924 / (7.85e-6 · 7211²)  =  0.356 kN/mm לק"ג
```
לכן ה-SHS וה-L90 יצאו **0.353 ו-0.355** — כמעט זהים. ⇒ **בחירת חתך של אלכסון היא החלטה של
כושר וקריסה, לא של קשיחות-ליחידת-משקל.** [חישוב]

**‏(ב) והיחס כולו תלוי בגודל אחד: הרזון של העמוד `h/i`:**
```
K/m של מסגרת מומנט = 12·E·i²/(ρ·h⁴)      היחס = (h/i)² · (h/L_d)² · cos²θ / 12
HE200B: i = √(5696/78.1) = 8.54 ס"מ  ⇒  h/i = 4000/85.4 = 46.8
היחס = 46.8² · (4000/7211)² · 0.6924/12 = 2192 · 0.3077 · 0.0577 = 38.9  ✔
```
⇒ ‏**כפיפה מפסידה כ-`(i/h)²`. עמוד HE200B בגובה 4 מ' ארוך פי 47 מרדיוס הגירציה שלו — ובריבוע,
פי 2192.** אין חתך שמסדר את זה: כדי להכפיל `i` צריך להכפיל את **גובה** הפרופיל.

### וכמה פלדה צריך כדי לקנות את אותה קשיחות בכפיפה? [חישוב]

```
HE360B = 43,190 סמ⁴ (לא מספיק)   HE400B = 57,680 סמ⁴ ✔
תוספת פלדה: (155 − 61.3) × 2 עמודים × 4 מ' = 749 ק"ג      מול האלכסון: 107 ק"ג
```
⇒ ‏**פי 7 פלדה, ועוד לא שילמת על ריפים, על פלטות קצה מוארכות ועל 2 חיבורי מומנט בשטח.**
‏🛑 ועם בסיס מפורק — **אין חתך שפותר את זה בכלל**: בלי בסיס מוגן ובלי צומת קשיח זה מנגנון.
⭐ **בשורה אחת: בין 8 ל-40 מונים, תלוי כמה נדיב אתה לחלופה. הסיבה היחידה — ‏צירי ~ 1/L · כפיפה ~ 1/h³.**

## א.4 מה **בדיוק** מתחזק — ומה לא. ניתוח מדויק

### ⛔ מה שאלכסון **לא** נותן

| | |
|---|---|
| ❌ אינו מגדיל את כושר ה**כפיפה** של הקורה | הקורה עוד נושאת בדיוק אותו `M_Rd`. אלכסון בפינה אינו קורה מחוזקת |
| ❌ אינו עוזר לעומס **אנכי** על הקורה | עומס מפוזר על הקורה עובר לעמודים בדיוק כמו קודם |
| ❌ אינו הופך צומת מפורק לקשיח | הצומת נשאר מפורק. השילוש עובד **סביבו** |
| ⚠️ ולמעשה **מוסיף** כוח למוטות | ראה א.5: הקורה מקבלת כוח **צירי** של 50 kN שלא היה לה |

### ✅ מה שהוא כן נותן — ארבעה דברים נפרדים

| # | מה | מנגנון + מספר מהמסגרת שלנו |

## א.7 איפה הכוח **באמת** נגמר — וזה לא באלכסון

⭐ שתי עובדות שהופכות אלכסון מ"מוט זול" ל"פרט יקר":
‏**(א) הכוח גדל ב-`1/cos θ`** — ‏50 kN בכניסה ⇒ ‏60.1 kN באלכסון, ובזווית 60° ⇒ פי 2 ⇒
‏**המחבר תמיד מתוכנן לכוח גדול מזה שבשרטוט הרוח.**
‏**(ב) הכוח מתרכז בשתי פינות** — רוח מפוזרת על 24 מ' קיר נהפכת ל-2 נקודות בגאסט, ומשם ל-2 עוגנים.

### המינימום המתמטי: **3 מישורים אנכיים לא-קוליניאריים**

הרוחבי** לו ⇒ ‏**אפס עיבור בשני האלכסונים** ⇒ אפס התנגדות ⇒ ‏**מנגנון פיתולי.**

### מה עושה חוסר סימטריה — במספרים

מבנה ‏24 × 12, ‏H = 200 kN בכיוון X. [חישוב, בהנחת **מישור גג קשיח**]

|---|---|---|
| לשדה X | ‏100 + 100 kN | ‏**200 kN בשדה אחד — פי 2** |
| פיתול על מרכז הקשיחות | ‏T = 0 | ‏T = 200 × 6 = **‏1200 kNm** |

| **עמוד פינה** (שייך לשני מישורים) | ‏100·4/6 = **‏66.7 kN** | ‏200·4/6 + 50·4/6 = **‏166.7 kN** |
| היחס בעמוד הפינה | | ‏**× 2.5** — ובעוגנים שלו גם כן |

⚠️ **סייג מוצהר:** מניח מישור גג **קשיח**. גג פח בלי ייצוב פלאן אמיתי מתחלק לפי **שטח משיק**
ולא לפי קשיחות ⇒ מספרים אחרים. **הכימות המחייב הוא של הקונסטרוקטור**; כאן ‏**המנגנון וסדר הגודל**.

### קצוות מול אמצע — והטיעון התרמי [חישוב]

מבנה **‏24 מ'**, ‏ΔT = 40 K, ‏α = 12e-6 ⇒ התארכות חופשית ‏24000 · 12e-6 · 40 = **‏11.5 מ"מ**.

| מיקום השדות | מה קורה לתנועה | מה קורה לכוח |
|---|---|---|
| ‏**באמצע** (השליש התיכון) | הנקודה ה"קבועה" באמצע ⇒ כל חצי זז **‏5.8 מ"מ** | הקטן ביותר |

| ‏**בשני הקצוות** | ⚠️ המבנה **מוחזק משני צדדים** ⇒ התנועה נהפכת ל**כוח** | ‏σ = E·α·ΔT = ‏210000·12e-6·40 = ‏**100.8 MPa** ⇒ ב-`SHS100×100×5`: ‏**188 kN** |

**‏188 kN מול 19 kN של רוח — פי 10.** גם אם בפועל השדה עצמו גמיש (‏5.8 מ"מ × 37.7 = 217 kN,
אותו סדר גודל) — **המנגנון אמיתי, לא תיאורטי.**

🧲 **ומה בפועל מציל את זה, ואמיר יזהה מיד:** ‏**כלל הברזל של ⌀ = בורג + 2 מ"מ.** כל חיבור
מוברג יכול להחליק עד ~2 מ"מ בקטגוריה A. ‏**6 חיבורים לאורך המבנה סופגים את כל 11.5 המ"מ.**
⇒ ‏**כאן קטגוריה A היא לא "פשרה זולה" — היא מפרק ההתפשטות.** וזו בדיוק הסיבה שדרישת
‏**preloaded** בלי סיבה מוצהרת (פרק 1 של הדוח) היא לא רק יקרה — היא **גם מבטלת את המפרק הזה.**

## ב.6 החלופות — ומה כל אחת עולה **ליצרן**

| החלופה | מתי היא הכרחית | מה זה עולה **לארץ ברזל** |

| ‏**מסגרות מומנט** | האדריכל אוסר אלכסון (חלון ראווה, מעבר) | ⭐ ‏**כל צומת קורה-עמוד הופך לפרט כבד.** מסגרת 3 קומות × 4 מפתחים = ‏**15 צמתי מומנט** במקום ‏6 קצות אלכסון. פלטות קצה מוארכות, ‏**ריפים**, לפעמים ברגים מותחים, עמודים בחתך גדול (א.3: ‏HE400B במקום ‏HE200B), ‏**רגישות סבילות גבוהה** בשטח |

| ‏**‏K** | קומות גבוהות, פירוק לגבהים | מכניס כוח ל**אמצע העמוד** ⇒ פרט באמצע עמוד = ריתוך במקום לא נוח |
| ‏**מוטות מתיחה** | קל, אסתטי, שיפוצים | עיניות, מותחנים, מתיחה מוקדמת מבוקרת — **הרבה פרטים קטנים ומדויקים.** וקשיחות 19% (א.6) |
| ‏**דיאפרגמת פח** כמישור גג | חוסכת ייצוב פלאן | דורשת פרט חיבור פח מוסמך ותיעוד — ‏**לא "הפח שממילא שם"** |

## ב.7 ⭐ מה זה אומר מסחרית לארץ ברזל

### **פלדה זולה, מחברים יקרים.** זו כל התמצית
[חישוב] שדה מיוצב אחד, ‏6×4, אלכסון בודד `SHS100×100×5`:

| הפריט | כמות | הערה |
|---|---|---|
| ‏**האלכסון** | ‏**107 ק"ג** | קטלוג. חיתוך אחד בכל קצה |
| ‏2 גאסטים ‏500×500×12 | ‏**47 ק"ג** | ‏= 44% ממשקל האלכסון… |
| קונטור לא-מלבני | ‏2 חלקים | ‏…אבל **‏LINE→JOIN→PLATE**, לא מקטלוג |
| חורים | ‏10 × ⌀18 | ‏[נמדד] ⌀ = בורג + 2 |
| ריתוך | ‏2 × 175 מ"מ ב-a=6 | ‏+ ריתוך פלטת הצומת |
| הרכבה | מותחן / חור אובלי | ראה ב.8 |

⇒ ‏**החומר במחבר הוא 44% מהאלכסון; העלות במחבר היא הרוב המכריע** — פרופיל, קידוח, ריתוך, שינוע,
צבע על שטח פנים גדול, והכול על **גיאומטריה שאינה חוזרת.**

### ⭐ למה כוחות האלכסון של הקונסטרוקטור **קובעים את הכיס שלך**
`N` ⇒ מספר ברגים ⇒ מרחקי קצה ⇒ **מידות הגאסט** ⇒ עובי הגאסט ⇒ אורך הריתוך ⇒ העוגנים ⇒ היסוד.
‏**שורה אחת בטבלת עומסים מכתיבה 7 החלטות ייצור** ⇒ שווה 3 דקות של בדיקה:

| # | מה לבדוק כששרטוט מגיע | איך, ב-30 שניות |
|---|---|---|
| **1** | ‏**האם `N` מתאים לגיאומטריה של השדה?** | קרא `B` ו-`h` מהשרטוט. ‏`N` צריך להיות ‏`V/cos θ`. אם `N = V` — או שקיבלת **גזירת קומה** ולא כוח אלכסון, או ש-`1/cos θ` נשכח. **‏6×4 ⇒ פער של 20%** |
| **2** | ‏**האם הכוחות גדלים כלפי מטה?** | ב.3: פי 3.7 בין קומה 3 לקומה 1. אם כל הקומות זהות — **מישהו העתיק** |
| **3** | ‏**נקודת עבודה** — האם 3 הצירים נפגשים? | אם האלכסון מפספס ב-`e`: ‏[חישוב] ‏N=264 kN × e=50 מ"מ = ‏**13.2 kNm** שמישהו נושא. **מי?** |
| **4** | ‏**עובי הגאסט — האם הוא לפי מאמץ או לפי יציבות?** | ⭐ [חישוב] ‏N=264 kN, ‏5 ברגים בפסיעה 60, ‏Whitmore = ‏2·240·tan30° = ‏**277 מ"מ** ⇒ ל-S355 דרושים ‏264400/(277·355) = ‏**‏2.7 מ"מ**. והפלטה 12. ⇒ ‏**העובי כולו נקבע ע"י קריסה וקצה חופשי, לא ע"י מאמץ** ⇒ **אל תדללו גאסט לפי חישוב מאמץ** |
| **5** | **קצה חופשי** | ‏[נוהג] הקריטריון המקובל ‏`L_free ≤ ~2.06·t·√(E/f_y)`. ל-`t=12` ב-S355: ‏2.06·12·24.3 = ‏**601 מ"מ**. גאסט 500×500 — **בפנים, בקושי.** ‏⚠️ **המקדם משתנה בין מקורות** — לא סעיף תקן חד |
| **6** | ‏**האם הגאסט הועתק מעבודה אחרת?** | חפש אותו גאסט בשלוש קומות שונות או בשני פרויקטים. **ההעתקה זולה בשרטוט ויקרה בשטח** |
| **7** | ‏**האם בסיסי העמודים המיוצבים שונים משאר הבסיסים?** | ⛔ ב.3: ‏**280 kN תלישה.** אם הפרט זהה לבסיס לחיצה רגיל — **שאלה, לפני הייצור** |

### 💰 ושלושה מספרים לשיחה מול הקונסטרוקטור

| | |
|---|---|
| ‏**‏1/cos θ** | לשדה 6×4 המחבר תמיד ב-‏**+20%** מעל כוח הרוח. אם הוא מתוכנן ל-`V` — הוא קטן ב-20% |
| ‏**‏× 3.7** | הפרש הכוח בין הגאסט העליון לתחתון ב-3 קומות. גאסט אחד לכולם = **פי 3.7 מיותר, או פי 3.7 חסר** |
| ‏**‏× 7 פלדה** | מה שעולה לוותר על אלכסון ולעבור לכפיפה (‏HE400B במקום ‏HE200B), ‏**לפני** 15 צמתי מומנט |
| ‏**חזרתיות** | ‏[חישוב] תקנון על הגאסט התחתון לכל הקומות: ‏3 קומות × 2 כיוונים × 2 שדות = עד ‏**12 גאסטים שונים** מול ‏**‏1**. עונש חומר: ‏(12 מ"מ במקום 10) × 8 פלטות × 4 ק"ג = **‏32 ק"ג**. תמורה: ‏**‏11 תוכניות חיתוך ופחות טעויות שטח.** ‏**זה ניצחון גדול בכסף** — וזה בדיוק אותו טיעון של "‏7 עוביים ו-100 תוכניות חיתוך" מפרק 8 של הדוח |

## ב.8 מבט המרכיב — שדה האלכסונים עולה **ראשון**

‏[נוהג] הרצף בשטח, ולא בגלל אסתטיקה: ‏**‏(1) שדה האלכסונים עולה ראשון ⇒ ‏(2) מפלסים ומאנכים
אותו (plumb) ⇒ ‏(3) הוא נהפך ל-DATUM ⇒ ‏(4) שאר המסגרת נתלית עליו.**

| למה | הסבר |
|---|---|
| **הוא היחיד שעומד לבד** | א.4 סעיף 4. שאר המסגרת היא מנגנון עד שהוא מחובר |
| **הוא הריבוע האמיתי** | מסגרת משולשת **אינה יכולה** לצאת מריבוע בלי לשנות אורך אלכסון ⇒ ‏**מדידת האלכסון היא בדיקת הריבוע.** זה גם מה שמפלסים לפיו |
| ⛔ ‏**ייצוב זמני עד שהקבוע בפנים** | כבלים / זוויתנים מוברגים. ‏**אין מפרקים ייצוב זמני לפני שהאלכסון הקבוע הודק ואומת** — זה סעיף בטיחות, לא נוחות |
| **האלכסון חייב להיות מתכוונן** | ‏[נמדד] בשיעור 6, שלב ד': שני חורים אובליים ב-2 פלטות — ‏**סלוט לאורך Y בפלטה אחת, לאורך Z בשנייה, נחתכים בדיוק במיקום הבורג.** ⇒ ‏**התאמה בשני כיוונים בשטח.** זה בדיוק המנגנון שמאפשר להרכיב אלכסון למרות שהמסגרת אף פעם לא מדויקת |
| **פלטת ההצטלבות בצלב** | ‏[נמדד] במסגרת D של אמיר הפער היה ‏**133.3 מ"מ**, והנוסחה המלאה דורשת ‏**298**. ⇒ הפרט שם עוד לא נסגר, ובלי הפלטה **הלחוץ מאבד את 0.5L** (ב.5). **שאלה לאמיר** |

# 🎯 סיכום — מה חושבים שאלכסון עושה, ומה הוא עושה

| ‏# | מה חושבים | ‏**מה זה באמת** |
|---|---|---|
| ‏1 | "מחזק את המסגרת" | ‏**הופך מנגנון לקונסטרוקציה.** בלי אלכסון וללא צמתים קשיחים הקשיחות היא **אפס** — לא "נמוכה" |
| ‏2 | "עוזר לקורות" | ‏**אפס תרומה לכפיפת הקורה**, ולמעשה **מוסיף לה** כוח צירי (‏50 kN בדוגמה) שלא היה שם |
| ‏3 | "אלכסון עבה יותר = טוב יותר" | הקשיחות **לק"ג אינה תלויה בחתך** (א.3א). החתך נקבע ע"י ‏**קריסה**, ואלכסון גדול יותר רק **מגדיל** את מה שהגאסט והיסוד סופגים |
| ‏4 | "האלכסון נושא את כוח הרוח" | נושא ‏**H/cos θ** — ‏**+20%** ב-34°, ‏**+124%** ב-63° |
| ‏5 | "האלכסון תלול = חזק" | ‏**האופטימום הוא 35.26°** (`B = h√2`), והוא **שטוח**: ‏27°–45° בתוך 8%. תלול = כוח כפול בגאסט |
| ‏6 | "שדה אחד בכיוון מספיק" | ‏**מישור אחד לכיוון = מנגנון פיתולי**, והשדה היחיד לוקח **‏100% ולא 50%** ⇒ עמוד פינה ב-**×2.5** |
| ‏7 | "אפשר לשים אותם בכל מקום בפלאן" | חוסר סימטריה **מזליג כוח לכיוון שאין בו רוח** (‏50 kN בשדות Y מרוח ב-X), ושדות בשני **קצוות** מבנה 24 מ' יוצרים ‏**‏100.8 MPa תרמי = 188 kN** |
| ‏8 | "אותו פרט לכל הקומות" | ‏**התחתון נושא את הסכום: ×3.7 בכוח, ×7 בעמוד, 280 kN תלישה בבסיס** |
| ‏9 | "אלכסון = פלדה זולה" | ‏**פלדה זולה, מחברים יקרים.** ‏107 ק"ג מוט מול ‏47 ק"ג גאסט + ‏10 חורים + ‏350 מ"מ ריתוך + גיאומטריה שאינה חוזרת |
| ‏10 | "זה בשביל רוח" | ‏**גם** אי-שלמויות (‏φ₀=1/200 ⇒ 4 kN לקומה, יכול לקבוע), ‏**גם** אורך קריסה (‏**×4–6** על `N_cr` בחינם), ‏**גם** ‏P-Delta (‏α_cr 188 מול 5.6), ‏**וגם** יציבות בהרכבה — ו**הוא ה-datum שמפלסים לפיו** |
