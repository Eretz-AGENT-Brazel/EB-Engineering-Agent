| השאלה | התשובה הקצרה |
|---|---|
| שיטות חיבור **בברגים** | חמש **קטגוריות** (‏EN 1993-1-8: ‏A/B/C במגירה, ‏D/E במשיכה) × שבע **טיפולוגיות** (פלטת קצה, פלטת גזירה, זוג זוויתנים, שחבור, פלטת בסיס, גאסט, מושב) |

| **שיטות אחרות** | **כן, שמונה לפחות**: פינים · מוטות מתיחה · ברגים חד-צדדיים (‏blind) · חיבורי מלחציים (‏clamps) · ברגים קודחים · מסמרות · יציקות · הדבקה. ולכל אחת נישה אמיתית |
| **יתרונות/חסרונות** | טבלת 12 קריטריונים. הכלל שמנצח: **מרתכים בבית-מלאכה, מבריגים בשטח** |
| **חיזוק אלכסונים** | מה זה נותן (מסלול עומס אופקי + ייצוב), שש טיפולוגיות, ותכנון המחבר בשמונה צעדים — עם דוגמת מספרים על המסגרת שאמיר עצמו מידל היום |
| **השאלות לפני בחירת מחבר** | ‏**24 שאלות בשש קבוצות**, בסדר שבו הן באמת נשאלות בבית-מלאכה |
| מה שהוספתי מעצמי | פרק **פרופילים חלולים** (‏CIDECT: ‏T/Y/X/K/N, punching shear) · פרק **מהמחבר אל המודל** — כל טיפוס וה-op/מאקרו שמייצר אותו אצלנו · ופרק **value engineering** עם המספרים של EB |
