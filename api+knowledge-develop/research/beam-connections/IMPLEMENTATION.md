# ⭐⭐⭐ שלושה דברים שהתוכנה לימדה אותי — ואחד מהם מתקן את המחקר עצמו

## 1. הסירוב של `boltparts` היה **הנדסה נכונה**, לא באג

ניסיתי את הפרט ה"מתבקש": **פלטת סכין בתוך הצינור, וברגים דרך הדפנות**.
```
דופן הצינור   z 95 … 100          פלטת הסכין   z −6 … +6
⇒ החבילה מכילה 89 מ"מ של חלל פנימי
boltparts → created=0
```
בורג שחוצה 89 מ"מ אוויר נמצא בכפיפה, והאום אינו נגיש. **הפרק 6 של הדוח שלי אומר את זה במשפט
אחד — ואני עצמי הפרתי אותו בבנייה.** ⇒ הפרט שונה: **ריתוך בצומת, הברגה בלפוף.**
🧲 **הלקח שנרשם: כשהתוכנה מסרבת, לפני שמחפשים עקיפה — לקרוא את הגיאומטריה. לפעמים הסירוב הוא
הכלל.**

## 2. ‏`collision minvol=100` תפס **שני פגמים שלי** שאף שער אחר לא רואה

| הפגיעות | הסיבה | התיקון |
|---|---|---|
| ‏4 פגיעות ‏~400 מ"מ מכל פינה | **ה-setback נמדד לציר ולא למעטפת.** פינת המעטפת יושבת חצי-רוחב מהציר, ולכן היא נכנסת למיתר זמן רב אחרי שהציר כבר פינה אותו | ‏`s ≥ (hw·|p·n| + clear)/|u·n|` ⇒ ‏385.6 ⇒ **400** במקום 250 |
| ‏4 פגיעות בגובה הברגים | **הברגים חדרו לצינור שהפלטה יושבת עליו** — לפוף שמוברג *מעל* מוט חייב שהמוט יהיה מקודח, אחרת הבורג פוגע בו | הזזת קבוצת הברגים **מחוץ לטביעת הצינור** (‏135–180 מ"מ מהציר, והקצה ב-100) |
| ‏2 פגיעות בצומת | הפער נקבע **בדיוק** לפי הנוסחה ⇒ **משיק** ⇒ טסלציה נוגעת | נוסחה מתוקנת + **5 מ"מ מרווח נומינלי** |
⭐ **‏`vfy_fit` ו-JOINT AUDIT היו ירוקים בכל שלושת המקרים.** רק בדיקת ההתנגשויות ראתה אותם.
⇒ **בדיקת התנגשויות אינה קוסמטיקה — היא השער שרואה גיאומטריה שאף שער אחר לא בודק.**

## 3. 🛑 והחשוב מכולם: **המודל תיקן את המחקר**

בדוח כתבתי שאורך ההפסקה הוא `w / sin φ`. **זה חסר.** הוא מפנה את רוחב המוט ה**רצוף** בלבד,
ומתעלם מכך שגם למוט ה**מופסק** יש רוחב ופאת קצה מרובעת:
```
נקודה על פאת הקצה:   P = −s·u_B + t·p_B ,   t ∈ [−w_B/2, +w_B/2]
מרחק מציר המוט הרצוף: P·p_A = s·sin φ + t·cos φ
הפינה הגרועה (t = −w_B/2) קובעת:

     חצי-פער  ≥  ( w_A/2 + (w_B/2)·cos φ ) / sin φ
```
| | האיבר הראשון בלבד | הנוסחה המלאה |
|---|---|---|
| חצי-פער (‏φ=58.11°, ‏200/200) | ‏117.8 | **‏180.0** |
| פער מלא | ‏235.6 | **‏360.0** |
| התנגשויות בפועל | **‏2** | **‏0** (עם +5 מרווח) |
⇒ **תת-הערכה של 53%.** ‏`w/sinφ` נכון למוט או פלטה דקה — **ושגוי לפרופיל ברוחב דומה.**
הדוח תוקן במקום, וה-PDF נוצר מחדש.

🔎 **ומה זה אומר על המסגרת של אמיר:** הפער שלו נמדד **133.3 מ"מ** בזווית 67.4° וברוחב 200 ⇒
הנוסחה המלאה דורשת `(100 + 100·cos67.4°)/sin67.4° = 149.0` לצד, כלומר **298 מ"מ**.
⇒ **הפער שם קטן מהנדרש** ⇒ הפרט לא נסגר — ומתלכד עם שתי הפלטות ששורטטו ונמחקו. **שאלה לאמיר.**
