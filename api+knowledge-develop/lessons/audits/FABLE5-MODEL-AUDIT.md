# 3️⃣ איך משתפרים — ידע הסוכן ושליטה בתוכנה
1. **חוק הזהב החדש: ספירה זהה ≠ מודל זהה.** כל ביקורת משווה **גיאומטריה + כיוון + תכונות פר-אובייקט**, לכל סוגי האובייקטים — לא רק לפרופילים.
2. **חוק המשקל (BOM parity):** חישוב משקל אמיתי פר-מחלקה (לא bbox) מקור-מול-עותק, שער ±1%. סטייה של 35 טון חייבת לצרוח, לא לעבור.
3. **סמנטיקה לפני גיאומטריה:** שם שכבה = מידע ("marug 4+1" = פח מדרך 4+1!). לקרוא שכבה → לסווג תפקיד → לבחור אסטרטגיית מידול. לעולם לא לשכפל bbox בעיוורון.
4. **חיבור = אובייקט עם יחסים:** לעולם לא ליצור בורג בלי hosts. בורג בלי קידוח אינו חיבור. השדרוג: איתור החלקים הנפגשים → `AddObject(hosts)` → חורים אמיתיים; ובעתיד — שחזור ברמת "חיבור" (מאקרו פלטת-קצה/יסוד) במקום פלטה+ברגים בודדים.
5. **השדרוג הטכני בעל הערך הגבוה ביותר: להוסיף `Ecs` לשורות PLATE/BOLT בקורא** (Entity-level — המסלול הבטוח שכבר עובד לפרופילים). זה נותן את הכיוון-במישור המדויק ומחסל את מחלקת "96 המסובבות" ואת צירי הברגים.
6. **בדיקת round-trip לכל תכונה:** יצרת עם mirror? קרא חזרה וודא שהדגל נקלט. `SetShapeMirror` נכשל בשקט — ואיש לא בדק.
7. **היגיינת נתונים:** בדיקות-עשן רק מחוץ לאזור העבודה + מחיקה מיידית; לעולם לא לנתח דאמפ שמכיל ארטיפקטים של עצמך (זה מקור שגיאת ה-15.3 מ').
8. **אימות ויזואלי:** אחרי כל בנייה — צילומי 4 מבטים קבועים זה-מול-זה. אמיר ראה בעין מה שהספירות פספסו.
