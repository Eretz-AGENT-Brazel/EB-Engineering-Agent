*מקור: מדידות ישירות מהמודלים של אמיר + הגדרותיו המפורשות. זהו הבסיס הפרקטי שאליו מחקר העיגון
צריך להתחבר — לא חומר גנרי, אלא מה שהמפעל באמת מבצע.*

## 🔑 העובדה שהמחקר חייב להסביר: **שני מרווחי חורים שונים**

```
עוגן יצוק ברצפה :  בורג M20  →  חור ⌀28   →  מרווח 8 מ"מ
עוגן קדוח בקיר  :  בורג M24  →  חור ⌀27   →  מרווח 3 מ"מ
חיבור פלדה-פלדה :  בורג M20  →  חור ⌀23   →  מרווח 3 מ"מ
                   בורג M16  →  חור ⌀19   →  מרווח 3 מ"מ
```

**ההשערה שגזרתי מהמספרים (טעונה אימות במחקר):** ברצפה **יוצקים** את העוגנים מראש, ואי-דיוק
היציקה גדול → חור נדיב (ואז **חובה דסקית פלטה**). בקיר **קודחים** לתוך בטון קיים → הקידוח במקום,
הדיוק גבוה, 3 מ"מ מספיק.

**מה שהמחקר צריך לקבוע:** האם 8 מ"מ הוא בכלל מספיק לעוגן יצוק, מה התקן דורש (AISC DG1 נותן
הרבה יותר — עד ~+14 מ"מ ל-M20), ומה גודל דסקית הפלטה הנדרשת.

## שאלות פתוחות שהמחקר צריך לענות עליהן
1. **עומק עיגון 120 מ"מ ל-M20** — האם זה עומד בקריטריון קונוס הבטון? מה `hef` המינימלי הנדרש?
   (‏120/20 = 6d — האם זה מספיק?)
2. **מרווח 8 מ"מ בחור פלטת בסיס** — מה התקן מחייב, ומה גודל/עובי דסקית הפלטה?
3. **העברת גזירה** — בפרטים של אמיר אין shear lug. האם החיכוך מספיק? מתי נדרש מפתח גזירה?
4. **מרחק קצה 50 מ"מ** בפלטה 400 — מה מרחק הקצה המינימלי **בבטון** (לא בפלטה) לעוגן M20?
5. **פלטות קיר בעמוד בטון 800×800** — עם 6 חורים במרווח 452, העוגנים קרובים לקצוות העמוד.
   מה מגבלת `c1` ומה קורה לכשל קצה בגזירה?
6. **ריפים** — האם הם משפיעים על תכן הפלטה (הקטנת העובי הנדרש), ומהו הכלל?
