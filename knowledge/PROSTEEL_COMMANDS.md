# ProSteel / ProStructures Command Reference

Extracted from ProSteel_AutoCAD.chm. Type these at the AutoCAD command line (prefix _ forces English).

| Command | Function | Description |
|---|---|---|
| `PSN_HANDRAIL` | Handrail Rail Connection dialog | Used to specify parameters for handrails created along shapes. |
| `PSN_STAIRS` | Extended Stairs dialog | Used to create complex, parametric stair cases and appurtenances. |
| `PSN_STAIRSCONN` | Standard Stair dialog | Use to create parametric stairs with stair run cases, various geometry calculation methods, different landing types, stringer cuts, and parametric constraints. |
| `PS_ADD_PLATE_FLANGE` | Bend Plates dialog | Used to add edged or bent segments to the plate. |
| `PS_ADD_SECTION` | Shape Segment | A shape can also be executed as a so-called cranked shape. For this purpose, bent or straight segments will be added to a straight or already cranked shape. |
| `PS_ANCHORBOLT` | ProSteel Bolt Styles dialog | Used to create anchor bolts individually, in a rectangular pattern, or a circular pattern by parametrically specifiying details for various types of anchor bolts, dowels, or studs. |
| `PS_BATCH_CLEAN_DWG` | Batch - Create native drawings dialog | Used to process all drawings in a selected directory into native drawings as a batch to avoid the need to process drawings individually. |
| `PS_BATCH_CREATE_ACIS` | Batch - Create ACIS DWG dialog | Used to process all drawings in a selected directory into ACIS DWG files as a batch to avoid the need to process drawings individually. |
| `PS_BENCHMARK` | Benchmark dialog | Used to add a benchmark (i.e., North symbol) to your model, which may be evaluated at later stages of modeling or drawing production in different ways. |
| `PS_BOLT` | Bolt Styles dialog | Used to parametrically add individual bolts, nuts, washers, and holes to model bolted connections. |
| `PS_BRACING` | Bracing dialog | Used to parametrically create bracing, along with gusset plate connections. |
| `PS_CIRCULAR_STAIRS` | (Circular) Stair dialog |  |
| `PS_COLLISION` | Collision Check dialog |  |
| `PS_CONST` | Construction dialog | Used to create general construction lines or measure distances in model. |
| `PS_COPY` | Copy/Mirror/Move/Align dialog | Used to manipulate model objects with constraints helpful for structural modeling and detailing. |
| `PS_CRANKEDVIEW` | Cranked 2D-View |  |
| `PS_CREATE_PARTLIST` | Parts List Processing Main Window |  |
| `PS_CREATE_SOPRO` | User Shape Manager dialog |  |
| `PS_DETCENTER` | DetailCenter Modes |  |
| `PS_DETCENTER_EXPRESS` | Starting DetailCenter Express |  |
| `PS_DIM` | Measured dialog | Used to create dimensions for 2D detailing. |
| `PS_DISPATCH` | Dispatch Blocks dialog | Used to distribute multiple AutoCAD blocks evenly across a shape length. |
| `PS_DRILL` | Drill dialog | Used to create holes for bolted connections manually, with a variety of parametric features such as countersinking, threads, step borings, and oblong shapes. |
| `PS_DWG_CONTAINLIST` | Groups Drawing Containment List dialog |  |
| `PS_DWG_INFO` | Drawing Information Table dialog | Used to add drawing information which is used to fill the title block of a 2D drawing associated with the selected parts. |
| `PS_DWG_PARTLIST` | Drawing Partlist dialog |  |
| `PS_EDIT_CONNECTIONS` | Connection Editor dialog | Used to edit and exchange all connections of a construction. |
| `PS_ENDPLATE` | Endplates dialog |  |
| `PS_EXCHANGE_MAP` | Names at Data Exchange dialog |  |
| `PS_EXPORT` | Data Export Command | Used to initiate exporting model data from ProSteel into other programs via external file formats (exchange files). |
| `PS_FAMILY_CLASS` | Part Families dialog | Used to organize ProSteel objects into Part Families. |
| `PS_FRAME` | Portal Frame dialog |  |
| `PS_GLOBAL_SETTINGS` | ProSteel Options dialog | Used to enter the standard settings for several functions. |
| `PS_GROUNDPL` | DSTV Baseplate dialog | Used to add a baseplate with detailing per the German DSTV standard. |
| `PS_GROUP` | Administrate Groups dialog | Used to manage groups, sub-groups, and assemblies. |
| `PS_GUSSET_PLATE` | Gusset Plate Connection dialog | Used to create a gusset plate for a connection. |
| `PS_HANDRAIL` | Handrail dialog | Used to add a parametric handrail along a polyline. |
| `PS_HELP` | ProSteel V8i (SELECTseries 6) R1 for AutoCAD |  |
| `PS_HIDE` | Hide tools | Used to hide components or whole groups. |
| `PS_HIDE_CLASS` | Display Classes dialog | Used to organize ProSteel objects from different layers into Display Classes. |
| `PS_HOLE_DISPLAY_STYLE` | Hole Display Styles dialog |  |
| `PS_IMPORT` | Data Import Command | Used to initiate importing data from external file formats (exchange files) into the current ProSteel model. |
| `PS_INSERT_MANDIM` | Manual Dimensioning Points |  |
| `PS_INS_PROF` | Shapes dialog |  |
| `PS_JOIST` | Joists dialog | Used to add American joists to the 3D model. |
| `PS_KOTE` | Elevation Flags dialog | Used to insert elevations for component parts in the display windows as well as to insert length and width distances as elevation symbols. The parameters length, width, and height  |
| `PS_LADDER` | Ladder dialog |  |
| `PS_LANGUAGE` | Language/Localization Selection dialog | Used to select the language and system of units in ProSteel. |
| `PS_LASCHE` | Splice Connection dialog | Used to add a splice connection between to colinear shapes. |
| `PS_MAN_CUT` | Manual 2D Cut dialog | Used to insert a cut into 2D details. |
| `PS_MIGRATE` | ProStructures Migration/Archiving Assistant dialog | Used to migrate existing ProStructures data into the current installation or to export data to a ProStructures Archive file. |
| `PS_MODIFY` | Element Modifications dialog | Used to modify 3D ProSteel model elements. |
| `PS_NC_DATA` | NC-Data dialog | Used to generate NC data from your ProSteel 3D model. |
| `PS_NOTCH` | Cope dialog |  |
| `PS_NOTCH_MAN` | Cope dialog - Shape End tab |  |
| `PS_OUTLET` | Notch dialog | Used to insert simple geometrical shapes of outlets and countersunk parts into your shapes. |
| `PS_PARTLIST` | Partslists Creation dialog |  |
| `PS_PFETTE` | Purlin dialog |  |
| `PS_PLATE` | Plates/Polyplates dialog |  |
| `PS_PLATE_EDITOR` | Plate Editor dialog | Used to modify flat plates, including boolean operations, edge, or chamfers. |
| `PS_POS` | Positionflags and Positioning dialog | Used to create or automatically generate position numbers and flags for parts in a 3D model for final detailing. |
| `PS_PPS` | DSTV Data export dialog | Used to export data from ProSteel to a PPS (Productions, Planning, and Control) program via an ASCII text file. |
| `PS_PROCESS_STATUS` | Process Status dialog | Used to assign a process status or color to parts. |
| `PS_PROJECT` | Project Management dialog | Used to manage stored project settings. |
| `PS_PROP_CHECK` | ProSteel Properties Dialogs |  |
| `PS_PURLIN_CONN` | Purlin Connection dialog | Used to create connections between purlins and roof girders. |
| `PS_RIP` | Stiffener dialog | Used to insert stiffeners in most shapes. |
| `PS_RIP_ANGLE` | Oblique Stiffeners |  |
| `PS_ROWADISPATCH` | Roof/Wall Panels dialog |  |
| `PS_SCHEARPLATE` | Shear Plate Connection dialog | Used to create a shear-only type connection consisting of a bolted and/or welded plate on the web of a supported member. |
| `PS_SEARCH` | Search Parts | Use this command to search for parts and components within a model, which meet certain requirements. |
| `PS_SETBKS` | Select View dialog | Used to manage the views, which are the result of the settings for a work frame. The views available in the model are sorted and displayed in this list. |
| `PS_STAIRS` | Stair dialog | Used to parametrically add a straight stair after picking insertion and vector points. |
| `PS_STATIK` | DSTV Analysis Interface dialog | Used to transfer information from a structural analysis program (e.g., Dlubal RFEM and RSTAB) into your model. |
| `PS_STEGW` | Web Angle Connection dialog |  |
| `PS_TEXTFLAG` | Create annotation label dialog | Used to create and edit manual annotations. |
| `PS_TRUSS` | Truss dialog |  |
| `PS_UNWIND` | ProSteel Unfold Pipe dialog |  |
| `PS_VERBAND` | Static Bracing dialog | Used to create bracing components. |
| `PS_VIEWPORT_FLATTEN` | Flatten Viewport dialog |  |
| `PS_VOUTE` | Haunch dialog |  |
| `PS_WORKFRAME` | Workframe dialog | Used to create a ProStructures workframe and add it to your model. |
