# בורגים וריתוך — EN 14399/15048, ISO 898, ISO 3834/5817/9606

## 1. היקף ותחולה (Scope)

מודול זה מכסה שתי משפחות חיבורים בפלדה קונסטרוקטיבית: **חיבורים מבורגים** ו**חיבורים מרותכים**, על פי מערך התקנים ההרמוני של CEN/ISO המשמש כבסיס ל‑ת"י 1225 (חוקת הפלדה) ול‑EN 1090‑2 (ביצוע מבני פלדה).

- **EN 14399** — מערכות בורגי חוזק‑גבוה **מתוחים‑מראש** (preloaded) לחיבורים קונסטרוקטיביים. חל כאשר נדרש כוח מתיחה מבוקר Fp,C: חיבורים חלקלקים‑עמידים (slip‑resistant, קטגוריות B/C), חיבורים במתיחה מתוחה‑מראש (קטגוריה E), עומסי עייפות ורעידות.
- **EN 15048** — מערכות בורגים קונסטרוקטיביים **לא‑מתוחים** (SB, Structural Bolting). חל בחיבורי גזירה/מגע רגילים (קטגוריות A/D) בהם די בהידוק "snug‑tight" ללא בקרת כוח.
- **ISO 898‑1** — תכונות מכניות של מחברים מפלדת פחמן/סגסוגת בעומס מתיחה (מגדיר את דרגות החוזק 8.8, 10.9 וכו').
- **ISO 3834** — דרישות איכות לתהליכי ריתוך התכה (מסגרת מערכת ניהול הריתוך של המפעל).
- **ISO 5817** — רמות איכות (מחלקות קבילות) לפגמי ריתוך התכה בפלדה/ניקל/טיטניום.
- **ISO 9606‑1** — הסמכת רתכים לפלדות. **ISO 15609‑1 / ISO 15614‑1** — מפרט (WPS) והכשרת נוהל ריתוך (WPQR). **EN 1011** — המלצות ביצוע ריתוך קשת.

## 3. שיטות תכן ובדיקות (Design methods & checks)

**א. כוח מתיחה‑מראש (EN 14399‑3/‑4; EN 1090‑2 §8):**
כוח המתיחה הנומינלי המינימלי — **Fp,C = 0.7 · fub · As** (EN 1090‑2 cl. 8.5.1 / EN 1993‑1‑8). זהו ~70% מכושר המתיחה. שיטות הידוק מוכרות: torque method, combined method, HRC (calibrated), DTI (EN 14399‑9).

**ב. עמידות בורג בגזירה (EN 1993‑1‑8):**
Fv,Rd = αv · fub · A / γM2, כאשר αv = 0.6 (דרגות 4.6/5.6/8.8) או 0.5 (10.9 כשמישור הגזירה בהברגה); A = As בהברגה.

**ג. עמידות במתיחה ועמידות מגע (bearing):**
Ft,Rd = k2 · fub · As / γM2 (k2 = 0.9); Fb,Rd = k1 · αb · fu · d · t / γM2.

**ד. עמידות להחלקה (slip resistance, קטגוריות B/C):**
Fs,Rd = ks · n · μ · (Fp,C − 0.8 · Ft,Ed) / γM3 — כאשר n = מספר משטחי החיכוך, ks מקדם צורת חור, μ מקדם החלקה (Table 3.7), Ft,Ed מתיחה חיצונית מקבילה.

**ה. הכשרת נוהל ריתוך (ISO 15614‑1):** עורכים pWPS → מרתכים ובודקים חתיכת מבחן (בדיקות ויזואלית, RT/UT, שבירה/כיפוף, מאקרו, קשיות) → מפיקים WPQR → מגזרים WPS לייצור בטווח שהוכשר.

**ו. הסמכת רתך (ISO 9606‑1):** מבחן מעשי לפי משתנים חיוניים (תהליך, צורה plate/pipe, סוג תפר butt/fillet, קבוצת חומר ISO/TR 15608, חומר מילוי, תנוחה, צד ריתוך). טווח הקבלה נגזר מעובי (t) וקוטר (D) חתיכת המבחן.

**ז. קבלת ריתוך (ISO 5817):** משווים כל אי‑שלמות (~26 סוגים) מול גבול הקבלה של הרמה הנדרשת (B/C/D). סדקים, חוסר התכה (lack of fusion) וחוסר חדירת שורש — **אינם קבילים בשום רמה**.

## 4. פרמטרים וערכים מרכזיים (Key values with clause)

**דרגות חוזק ISO 898‑1:2013 (§5, Table):**
- 8.8: fub = 800 MPa, fyb (Rp0.2) = 640 MPa (עבור d ≤ 16 mm; ל‑d > 16 mm: 830/660).
- 10.9: fub = 1000 MPa, fyb = 900 MPa.
(כלל הסימון: מספר ראשון = fub/100; מכפלת שני המספרים = fyb/10.)

**שטח מתיחה As (mm²) וכוח Fp,C לדרגה 10.9 (Fp,C = 0.7·fub·As):**
- M12: As 84.3 → 59 kN; M16: 157 → 110 kN; M20: 245 → 172 kN; M24: 353 → 247 kN; M27: 459 → 321 kN; M30: 561 → 393 kN; M36: 817 → 572 kN.

**מקדמי בטיחות חלקיים (EN 1993‑1‑8 / NA):** γM2 = 1.25 (עמידות בורגים/ריתוך); γM3 = 1.25 (החלקה ULS); γM3,ser = 1.1 (החלקה SLS).

**מקדם החלקה μ (EN 1993‑1‑8 Table 3.7, מהד' 2005):** מחלקת משטח A = 0.5; B = 0.4; C = 0.3; D = 0.2.

**רמות איכות ריתוך (ISO 5817):** B = מחמיר; C = ביניים; D = מקל. נקבוביות אחידה מוגבלת בשטח מוקרן ~2% / 4% / 8% ב‑B / C / D בהתאמה.

**מיפוי EXC ↔ ISO 5817 (EN 1090‑2 Table 17):** EXC1→D; EXC2→C; EXC3→B; EXC4→B (עם דרישות מחמירות נוספות). ברירת מחדל כשלא צוין: EXC2 / רמה C.

**קטגוריות חיבורים מבורגים (EN 1993‑1‑8 Table 3.2):** גזירה — A (bearing, לא‑מתוח), B (slip‑resistant SLS), C (slip‑resistant ULS); מתיחה — D (לא‑מתוח), E (מתוח‑מראש).

## 5. קשר ת"י ↔ EN

ת"י 1225 (חוקת הפלדה, חלקים 1–3) מבוסס על **EN 1993 (Eurocode 3)** עם התאמות לאומיות (עומסי רוח/רעש‑אדמה, מקדמים). דרישות הביצוע לחיבורים — בורגים וריתוך — נשענות על **EN 1090‑2**, המפנה ישירות ל‑EN 14399, EN 15048, ISO 3834, ISO 5817, ISO 9606‑1 ו‑ISO 15614‑1. תקני המוצר והריתוך אומצו בישראל כתקנים ישראליים תואמי‑EN (ת"י EN/ISO) דרך מכון התקנים (SII). המיפוי מבני EN הוא ישיר; ההתאמה הלאומית העיקרית היא במקדמי עומס/מהימנות ובנספחים לאומיים (NA), לא בערכי החומר של הבורג או במחלקות פגמי הריתוך.

## 7. הערות מעשיות ליצרן/מקים פלדה

- **שלמות מערכת הבורג:** ב‑EN 14399 יש לרכוש **סט מלא מאותו ספק ומאותה אצווה** (בורג+אום+דסקיות) — אין לערבב HR עם HV. יש לשמור על השימון (lubrication) המקורי; ניקוי/שימון מחדש משנה את יחס מומנט‑כוח ופוסל את הכיול.
- **הידוק מתוח‑מראש:** לתעד את שיטת ההידוק (torque/combined/HRC/DTI) ואת ערכי Fp,C היעד; combined method = הידוק ראשוני ~75% ואז סימון וסיבוב זווית מוגדר.
- **משטחי חיכוך:** בחיבורי slip‑resistant יש להכין את המשטח למחלקה הנדרשת (ניקוי שלד, מתכת מותכת/צבע אבץ‑סיליקט) ולתעד את μ; לא לצבוע את אזור המגע בצבע רגיל.
- **ריתוך:** לנהל WPS מאושר לכל צירוף (חומר, עובי, תנוחה); רתכים בעלי הסמכת ISO 9606‑1 בתוקף; לחשב חימום מקדים לפי EN 1011‑2 (שיטת CET, נספח C) למניעת סדיקת מימן, ולמדוד טמפרטורה לפי ISO 13916.
- **NDT ובקרה:** להתאים היקף בדיקות (VT/PT/MT/RT/UT) לרמת ISO 5817 של ה‑EXC; לתעד HEAT numbers ותעודות EN 10204 3.1 לחומר הבסיס ולחומר המילוי לצורך עקיבות.
