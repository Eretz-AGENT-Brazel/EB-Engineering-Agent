# EN 1993-1-5 — אלמנטי לוח (EC3-1-5)

## 1. היקף ותחולה (Scope)

EN 1993-1-5 ("Design of steel structures — Part 1-5: Plated structural elements") נותן כללי תכן לאלמנטי לוח מפלדה הנתונים למאמצים במישור הלוח (in-plane), עם דגש על תופעות קריסת לוח (plate buckling) ו-shear lag שאינן מכוסות ב-EN 1993-1-1. הוא חל על קורות מורכבות מרותכות (plate girders), נפשים גבוהים, מיכלים, גשרים ואלמנטים מחתך class 4 שבהם ה-web/flange דק דיו כדי שקריסה מקומית תגביל את הקיבולת. התקן מניח פלדה קונסטרוקטיבית לפי EN 1993-1-1 עם flat plates; לוחות מקומרים (corrugated) מטופלים ב-Annex D. הוא **אינו** מכסה עייפות, כללי חתכים דקי-דופן מגולגלים-קר (EN 1993-1-3), או קליעת פאנלים בעומס רוחבי. שלוש דרכי תכן מוצעות: (א) **effective width method** (הנפוצה, §§4–7), (ב) **reduced stress method** (§10), (ג) תכן בסיוע **FEM** (Annex C).

## 3. שיטות תכן ובדיקות (Design methods & checks)

**Shear lag (§3.1–3.2):** נבדק אם `b0 > Le/50` (b0 = חצי-רוחב פלנג' בין נפשים / outstand; Le = מרחק בין נקודות מומנט אפס). אם כן, מפחיתים לרוחב יעיל `beff = βs·b0`, כאשר `βs` תלוי בפרמטר `κ = α0·b0/Le`. ב-ULS מותר לשלב shear lag עם plate buckling דרך effective^s area.

**Effective width למאמצים ישרים / class 4 (§4.4):** לכל אלמנט לחוץ מחשבים גמישות יחסית
`λ̄p = √(fy/σcr) = (b̄/t)/(28.4·ε·√kσ)`, `ε = √(235/fy)`.
מקדם ההפחתה (Winter):
- **Internal element:** `ρ = 1.0` אם `λ̄p ≤ 0.5+√(0.085−0.055ψ)`; אחרת `ρ = (λ̄p − 0.055(3+ψ))/λ̄p² ≤ 1.0`.
- **Outstand element:** `ρ = 1.0` אם `λ̄p ≤ 0.748`; אחרת `ρ = (λ̄p − 0.188)/λ̄p² ≤ 1.0`.
הרוחב היעיל מתחלק לפי טבלאות 4.1/4.2. חתך יעיל → `Aeff`, `Weff`, ו-shift של הציר הנייטרלי `eN` (מוסיף `ΔMEd = NEd·eN`). מקשיחים אורכיים מטופלים כ-column-like / plate-like buckling עם אינטרפולציה (§4.5, Annex A).

**Resistance to shear (§5):** נדרשת בדיקה אם `hw/tw > 72ε/η` (נפש לא-מקושחת) או `> 31ε√kτ/η` (מקושחת).
`Vb,Rd = Vbw,Rd + Vbf,Rd ≤ η·fyw·hw·tw/(√3·γM1)`.
תרומת הנפש: `Vbw,Rd = χw·fyw·hw·tw/(√3·γM1)`, כאשר `λ̄w = 0.76·√(fyw/τcr)` או פרקטית `λ̄w = hw/(37.4·tw·ε·√kτ)`; `kτ` לפי Annex A.3 (מקשיחים רוחביים בלבד: `kτ = 5.34 + 4.00(hw/a)²` ל-`a/hw ≥ 1`, אחרת `4.00 + 5.34(hw/a)²`). `χw` לפי טבלה 5.1 (ראה §4). תרומת הפלנג' `Vbf,Rd` נוספת רק אם הפלנג' אינו מנוצל במלואו למומנט.

**Resistance to transverse forces / patch loading (§6):** `FRd = fyw·Leff·tw/γM1`, `Leff = χF·ly`. אורך טעינה יעיל `ly = ss + 2tf(1+√(m1+m2))` (m1, m2 פרמטרי §6.5). `χF = 0.5/λ̄F ≤ 1.0`, `λ̄F = √(ly·tw·fyw/Fcr)`, `Fcr = 0.9·kF·E·tw³/hw`. שלושה סוגי טעינה (Type a/b/c, איור 6.1) קובעים את `kF`.

**Interaction (§7):** כפיפה+גזירה (§7.1): אם `η̄3 = VEd/Vbw,Rd > 0.5` →
`η̄1 + (1 − Mf,Rd/Mpl,Rd)(2η̄3 − 1)² ≤ 1.0`. עומס מרוכז+כפיפה (§7.2): `η2 + 0.8·η1 ≤ 1.4`.

**Flange-induced buckling (§8):** למניעת קריסת הפלנג' הלחוץ אל תוך הנפש:
`hw/tw ≤ k·(E/fyf)·√(Aw/Afc)`, `k = 0.55 / 0.40 / 0.30` (מומנט אלסטי / פלסטי / עם רוטציה פלסטית).

## 4. פרמטרים וערכים מרכזיים (Key values)

- `ε = √(235/fy)` — §4.4 / EN 1993-1-1 Table 5.2.
- `χw` (Table 5.1): **rigid end post** — `λ̄w < 0.83/η → η`; `0.83/η ≤ λ̄w < 1.08 → 0.83/λ̄w`; `λ̄w ≥ 1.08 → 1.37/(0.7 + λ̄w)`. **non-rigid end post** — `λ̄w < 0.83/η → η`; `λ̄w ≥ 0.83/η → 0.83/λ̄w`.
- `η` (§5.1(2), NDP): מומלץ **1.20** לפלדות עד וכולל S460, ו-**1.00** מעל S460.
- `kσ` (Table 4.1, internal): `ψ=1 → 4.0`; `ψ=0 → 7.81`; `ψ=−1 (pure bending) → 23.9`. Outstand (Table 4.2): `ψ=1 → 0.43`.
- מקדם ה-Winter: קבוע `0.055(3+ψ)` (internal) ו-`0.188` (outstand) — §4.4(2).
- מקדם `σE = 190000·(tw/hw)²` [MPa]; `τcr = kτ·σE` — Annex A.3.
- `γM0 = 1.00`, `γM1 = 1.00` (ערך המלצת CEN — EN 1993-1-1 §6.1 NOTE 2B; נספח לאומי עשוי לקבוע 1.10, למשל גרמניה) ; ברוב בדיקות 1-5 קובע `γM1`.
- מגבלת בדיקת גזירה: `hw/tw > 72ε/η` (unstiffened) — §5.1(2).
- מקשיחי קצה נוקשים (rigid end post): §9.3.1 דורש שני מקשיחים דו-צדדיים במרחק `e > 0.1·hw`.
- flange-induced buckling `k`: 0.30 / 0.40 / 0.55 — §8(1).

## 5. קשר ת"י ↔ EN

ישראל מאמצת את Eurocode 3 דרך **ת"י 1225** ("חוקת הפלדה") עם National Annex ישראלי. חלק 1.1 (מהדורת 2023) מאמץ את EN 1993-1-1; אלמנטי לוח (EN 1993-1-5) מיושמים כחלק המקביל במשפחת ת"י 1225. המבנה ההנדסי, הנוסחאות ומקדמי ה-buckling זהים ל-EN; ה-NA הישראלי קובע בעיקר את ה-**NDPs**: ערכי `γM0/γM1`, ערך `η`, ומקדמים בטבלאות (בדרך כלל נשמרים ערכי ההמלצה של CEN). מיפוי החומרים (S235/S275/S355…) נשמר; יש לוודא את ערכי `γM` המדויקים מול ה-NA הישראלי לפני תכן.

## 7. הערות מעשיות ליצרן/מקים פלדה

- **מקשיחי קצה (end post):** ההבחנה rigid/non-rigid משפיעה ישירות על `χw` בערכי `λ̄w` גבוהים — end post נוקש (שני מקשיחים אנכיים היוצרים "short beam") מגדיל קיבולת גזירה משמעותית; לתעד בשרטוטי הייצור את סוג הקצה שהניח המתכנן.
- **patch loading בהרמה/הנחה:** קורות נפש-דקה רגישות לעומס מרוכז מקומי בעת הובלה, הנחה על saddles וריתוך; להשתמש ב-bearing stiffeners מתחת לעומסים מרוכזים ובנקודות תמיכה.
- **מקשיחים רוחביים ביניים:** מגדילים `kτ` ובכך `χw`; מרווח `a` קטן יותר משפר גזירה אך מוסיף עבודת ריתוך — לאזן.
- **imperfections לייצור:** סטיות ישרות ומקומיות של פאנלים משפיעות על ההנחות; לעמוד בסבולות EN 1090-2 (execution) כדי שהנחות ה-buckling יתקיימו.
- **class 4:** באלמנטים דקים, החתך היעיל שונה מהברוטו — לוודא שהחישוב הקונסטרוקטיבי והנח"צ (חורים, cope) אינם מקטינים עוד את `Aeff`.
- **ריתוך פלנג'-נפש:** flange-induced buckling מגביל `hw/tw`; בנפשים גבוהות מאוד ודקות מאוד יש להקפיד על מקשיחים ואיכות ריתוך.
