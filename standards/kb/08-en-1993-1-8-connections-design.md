# EN 1993-1-8 — תכן חיבורים (EC3-1-8)

> **הבהרה:** מודול זה הוא עזר-תכן בלבד. האחריות ההנדסית המלאה חלה על מהנדס רשוי החותם על התכן. הערכים מובאים כעובדות מתוך התקן/מקורות רשמיים; אימות מול הגרסה הרשמית העדכנית והנספח הלאומי הוא באחריות המשתמש.

## 1. היקף ותחולה (Scope)
EN 1993-1-8 קובע כללי תכן ל**חיבורים בקונסטרוקציות פלדה** תחת עומס סטטי בעיקרו (predominantly static): חיבורי **בורגים, מסמרות (rivets), פינים (pins) וריתוכים**. חל על מרכיבי חיבור מפלדות מבניות. הגרסה הישנה (2005) מכסה S235–S460; הגרסה החדשה (2024) הרחיבה עד S700. עובי חומר ≥ 3 mm. הפרק כולל גם **שיטת הרכיבים (component method)** לחישוב עמידות וקשיחות של חיבורי קורה-עמוד וחיבורי בסיס עמוד, וסיווג חיבורים (מפרקי / קשיח / חצי-קשיח). התקן משמש יחד עם EN 1993-1-1 ומניח ביצוע לפי **EN 1090-2**. אינו מכסה עומס עייפות (ראה EN 1993-1-9) או תנאי טעינה דינמיים חריגים.

## 3. שיטות תכן ובדיקות (Design Methods)

**קטגוריות בורגים (Table 3.4 / §3.4):**
- גזירה: **A** — bearing type (רגיל, ללא דריכה); **B** — slip-resistant ב-SLS; **C** — slip-resistant ב-ULS.
- מתיחה: **D** — non-preloaded; **E** — preloaded. בורגים דרוכים חייבים חוזק **8.8 או 10.9** בלבד.

**עמידות בורג בגזירה — Fv,Rd (Table 3.4):**
`Fv,Rd = αv · fub · A / γM2`
כאשר `αv = 0.6` למחלקות 4.6, 5.6, 8.8 (וכן כשמישור הגזירה עובר בגזע הלא-מוברג → A = גזע מלא Ag); `αv = 0.5` למחלקות 4.8, 5.8, 6.8, 10.9. כשמישור הגזירה בהברגה: `A = As` (שטח מתיחה). לכפל מישורי גזירה מכפילים במספר המישורים.

**עמידות במיסב — Fb,Rd (Table 3.4):**
`Fb,Rd = k1 · αb · fu · d · t / γM2`
- `αb = min(αd ; fub/fu ; 1.0)`; קצה: `αd = e1/(3d0)`; פנימי: `αd = p1/(3d0) − 1/4`.
- קצה (ניצב לכוח): `k1 = min(2.8·e2/d0 − 1.7 ; 1.4·p2/d0 − 1.7 ; 2.5)`; פנימי: `k1 = min(1.4·p2/d0 − 1.7 ; 2.5)`.
`fu` הוא של **החומר המחובר (plate)**, לא של הבורג.

**עמידות במתיחה — Ft,Rd (Table 3.4):**
`Ft,Rd = k2 · fub · As / γM2`, כאשר `k2 = 0.9` (בורג רגיל) או `0.63` (בורג שקוע countersunk).

**עמידות בניקוב ראש/אום — Bp,Rd (Table 3.4):**
`Bp,Rd = 0.6 · π · dm · tp · fu / γM2`; `dm` = ממוצע קוטר מעבר לפינות/מול פנים של ראש הבורג או האום. יש לבדוק כשלוחית דקה נמשכת ע"י הבורג.

**שילוב גזירה+מתיחה (Table 3.4):**
`Fv,Ed/Fv,Rd + Ft,Ed/(1.4·Ft,Rd) ≤ 1.0`.

**עמידות החלקה לבורגי חוזק-גבוה דרוכים — Fs,Rd (§3.9, Eq. 3.8):**
`Fs,Rd = ks · n · μ · Fp,C / γM3` (קטגוריה C, ULS).
בקטגוריה B (SLS) נעשה שימוש ב-γM3,ser. בנוכחות מתיחה חיצונית Ft,Ed המפחיתה את הדריכה:
`Fs,Rd = ks · n · μ · (Fp,C − 0.8·Ft,Ed) / γM3`.
כוח הדריכה: `Fp,C = 0.7 · fub · As` (§3.6.1). `n` = מספר משטחי החיכוך; `ks` לפי Table 3.6; `μ` לפי Table 3.7.

**ריתוך מילוי — Fillet weld (§4.5):**
- *שיטה כיוונית (directional, §4.5.3.2):* מפרקים את כוח היחידה למאמצים על מישור הגרון: `σ⊥, τ⊥, τ∥` (המאמץ `σ∥` המקביל לציר אינו נבדק). קריטריון: `√(σ⊥² + 3(τ⊥² + τ∥²)) ≤ fu/(βw·γM2)` **וגם** `σ⊥ ≤ 0.9·fu/γM2`.
- *שיטה מפושטת (simplified, §4.5.3.3):* משווים כוח שקול ליחידת אורך לעמידות תלת-ממדית: `Fw,Ed ≤ Fw,Rd = fvw,d · a`, כאשר `fvw,d = (fu/√3)/(βw·γM2)`. תמיד שמרנית או שווה לכיוונית.
- גובה גרון `a` = הגובה מהשורש למישור הפנים; `a ≥ 3 mm` (§4.5.2). אורך יעיל מינימלי: הגדול מבין `30 mm` או `6a`.

**ריתוך חריץ (butt/groove, §4.7):** חדירה מלאה — עמידות ≥ עמידות החומר החלש; חדירה חלקית — נבדק כריתוך מילוי עם גרון אפקטיבי.

**שיטת הרכיבים (component method, §6):** החיבור מפורק לרכיבים בסיסיים (T-stub במתיחה, אזור לחיץ בפאנל הגזירה, אוזן הכיפוף, לוחית קצה בכיפוף, אזור לחיצה של בטון בבסיס עמוד וכו'). לכל רכיב מחושבים עמידות וקשיחות; עמידות המומנט Mj,Rd נקבעת ע"י הרכיב החלש, וקשיחות התחלתית Sj,ini מסכום הקפיצים בטור. משמש לסיווג קשיח/חצי-קשיח/מפרקי ולתכן **בסיסי עמודים** ו**כוחות מנוף (prying)** — כוחות המנוף מוגברים כתוצאה מכיפוף הלוחית ומחייבים לוחית עבה דיה או שימוש בשיטת ה-T-stub.

## 4. פרמטרים וערכים מרכזיים (Key Facts)
- **γM2 = 1.25** (עמידות חתכים בכשל / בורגים / ריתוכים) — Table 2.1.
- **γM3 = 1.25** (החלקה ב-ULS, קט' C); **γM3,ser = 1.10** (החלקה ב-SLS, קט' B) — Table 2.1.
- **מחלקות בורגים (Table 3.1), fyb / fub [MPa]:** 4.6 → 240/400; 4.8 → 320/400; 5.6 → 300/500; 5.8 → 400/500; 6.8 → 480/600; 8.8 → 640/800; 10.9 → 900/1000.
- **αv:** 0.6 (4.6/5.6/8.8) ; 0.5 (4.8/5.8/6.8/10.9) — Table 3.4.
- **k2:** 0.9 (רגיל) / 0.63 (שקוע) — Table 3.4.
- **ks (Table 3.6):** חורים עגולים רגילים = 1.0; חורים מוארכים קצרים/מוגדלים ≈ 0.85; מוארכים ארוכים ≈ 0.7 (ובחלק מהמצבים 0.63).
- **μ slip factor (Table 3.7):** Class A (grit/shot-blasted, ללא חלודה) = **0.50**; Class B (alkali-zinc silicate 50–80 µm) = **0.40**; Class C (מוברש/ניקוי להבה) = **0.30**; Class D (לא-מטופל) = **0.20**.
- **βw correlation factor (Table 4.1):** S235 = **0.80**; S275 = **0.85**; S355 = **0.90**; S420 = **1.00**; S460 = **1.00**.
- **גרון ריתוך:** a ≥ 3 mm; אורך יעיל מינימלי = max(30 mm, 6a) — §4.5.
- **מרווחים (Table 3.3):** מרחק קצה מינ' `e1 ≥ 1.2 d0`, `e2 ≥ 1.2 d0`; מרווח `p1 ≥ 2.2 d0`, `p2 ≥ 2.4 d0`; מקסימום נגד קורוזיה/קימוט לפי `min(14t ; 200 mm)` ואחרים.
- **Fp,C = 0.7 fub As** (§3.6.1). לדוגמה M20 10.9: As = 245 mm² → Fp,C ≈ 172 kN.

## 5. קשר ת"י ↔ EN
ישראל אינה חברת CEN, ואין נספח לאומי ישראלי רשמי (NA) ל-EN 1993-1-8. תכן הפלדה בישראל נשען היסטורית על **ת"י 1225** (מבני פלדה), שבחלקיו מבוסס על גישות AISC/עומסים; חלק מהמשרדים בישראל מיישמים את ה-Eurocode כמסמך התייחסות מקצועי. יש לוודא מול המזמין/הרשות איזה קוד הוא המחייב בפרויקט. **המיפוי המדויק ת"י 1225 ↔ EN 1993-1-8 טעון אימות פרטני** (ראה uncertainties).

## 6. מהדורה ותוקף (נכון ליולי 2026)
- **EN 1993-1-8:2005** (כולל תיקוני AC) — המהדורה הנפוצה בשימוש עם נספחים לאומיים.
- **EN 1993-1-8:2024** — הדור השני (second generation), פורסמה ב-CEN במרץ 2024; מרחיבה עד S700, מבנה ומיספור עודכנו. תקופת מעבר (co-existence) עד ביטול הגרסה הישנה במדינות החברות (יעד סביב 2027–2028). יש לבדוק איזו מהדורה מחייבת בפרויקט הספציפי; מספרי הסעיפים כאן מתייחסים ל-**2005** אלא אם צוין אחרת.

## 7. הערות מעשיות ליצרן/מקים פלדה
- **קטגוריה C (slip-critical):** משטחי החיכוך חייבים הכנה מבוקרת (grit-blast ל-Sa 2½ לקבלת μ=0.5) ותיעוד; דריכה מבוקרת מומנט/סיבוב לפי EN 1090-2; אין לצבוע את אזור החיכוך אלא אם הצבע מסווג (למשל alkali-zinc silicate → Class B).
- **βw ↔ fu:** במעבר ל-S355 מקבלים גרון יעיל גבוה יותר (βw=0.9) — כדאי לתכנן ריתוכים בהתאם לגרייד הלוחות בפועל לפי תעודות היצרן (mill certs, EN 10204 3.1).
- **מיסב מול גזירה:** בחיבורי גזירה רבים המיסב (Fb,Rd) הוא הקובע, לא גזירת הבורג — יש לשמור מרחקי קצה/מרווחים כדי לא לחתוך את αb.
- **גרון מינ' 3 mm ואורך יעיל:** ריתוכים קצרים מ-30 mm/6a לא נחשבים נושאים — יש לתכנן אורכי ריתוך ריאליים.
- **prying:** בלוחיות קצה/פלנצ'ים דקים כוחות המנוף מגדילים משמעותית את המתיחה בבורג — יש לעבות לוחית או להשתמש בשיטת T-stub, ולא להזניח את התרומה.
- **בורגי 8.8/10.9 בלבד לדריכה;** אין להשתמש ב-4.6/5.6 כבורגי חוזק-גבוה דרוכים.
